# Docker Lab 7: Bind Mounts and Named Volumes

## Objective

Learn how to persist and share data between a Docker container and the host using bind mounts and named volumes.

## Directory Structure

```text
Docker/lab7/
└── nginx-bind/
    ├── conf/
    │   └── default.conf
    └── html/
        └── index.html
```

## 1. Create the Named Volume

Create a Docker volume to store Nginx log files.

```bash
docker volume create nginx_logs
docker volume ls
```

## 2. Prepare the HTML Page

The file `nginx-bind/html/index.html` contains the web page served by Nginx.

```html
Hello from Bind Mount - Updated
```

Because the HTML directory is bind-mounted, changes made to the file on the host are reflected in the running container.

## 3. Configure Nginx

The `nginx-bind/conf/default.conf` file configures Nginx to listen on port 80 and serve files from `/usr/share/nginx/html`.

```nginx
server {
    listen 80;
    server_name localhost;

    root /usr/share/nginx/html;
    index index.html;

    access_log /var/log/nginx/access.log;
    error_log /var/log/nginx/error.log notice;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

## 4. Run the Container

From the repository root in Ubuntu on WSL, use the following commands. The Docker CLI path below is specific to the lab environment; use `docker` directly if it works in your terminal.

```bash
DOCKER="/mnt/c/Program Files/Docker/Docker/resources/bin/docker.exe"

HTML_DIR="$(wslpath -w "$(realpath Docker/lab7/nginx-bind/html)")"
CONF_DIR="$(wslpath -w "$(realpath Docker/lab7/nginx-bind/conf)")"

"$DOCKER" run -d \
  --name nginx-lab7 \
  --platform linux/amd64 \
  -p 8082:80 \
  --mount type=volume,source=nginx_logs,target=/var/log/nginx \
  --mount "type=bind,source=$HTML_DIR,target=/usr/share/nginx/html" \
  --mount "type=bind,source=$CONF_DIR/default.conf,target=/etc/nginx/conf.d/default.conf,readonly" \
  nginx:stable
```

### Mounts Used

| Type | Source | Container destination | Purpose |
|---|---|---|---|
| Bind mount | `nginx-bind/html` | `/usr/share/nginx/html` | Serve host HTML files |
| Bind mount | `nginx-bind/conf/default.conf` | `/etc/nginx/conf.d/default.conf` | Configure Nginx |
| Named volume | `nginx_logs` | `/var/log/nginx` | Persist Nginx logs |

## 5. Verify the Web Page

```bash
curl http://localhost:8082
```

Expected output:

```text
Hello from Bind Mount - Updated
```

## 6. Verify the Bind Mount

Edit the host file:

```bash
echo "Hello from Bind Mount - Updated" > Docker/lab7/nginx-bind/html/index.html
```

Request the page again:

```bash
curl http://localhost:8082
```

The updated content should appear without rebuilding the image or recreating the container.

## 7. Verify the Named Volume and Logs

Inspect the container mounts:

```bash
"$DOCKER" inspect nginx-lab7
```

List the log files:

```bash
"$DOCKER" exec nginx-lab7 sh -c 'ls -l /var/log/nginx'
```

Display the access log:

```bash
"$DOCKER" exec nginx-lab7 cat /var/log/nginx/access.log
```

The access log should contain the HTTP request generated by `curl`, including the successful `200` response.

## 8. Clean Up

After verifying the logs, remove the lab container and named volume:

```bash
"$DOCKER" stop nginx-lab7
"$DOCKER" rm nginx-lab7
"$DOCKER" volume rm nginx_logs
```

**Note:** Removing the named volume deletes the logs stored in it. The HTML and Nginx configuration files remain on the host.
